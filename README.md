# AMMAR Perfumería | By Karen Rico 💎

Aplicativo web interactivo (SPA) y catálogo boutique de alta perfumería en Medellín, Colombia. 100% funcional en cliente (`index.html`) para despliegue local o alojamiento estático en GitHub Pages.

---

## 🌟 Características Principales

- **Arquitectura SPA (Single Page Application)**: Navegación fluida e instantánea sin recarga entre las páginas de **Inicio**, **Catálogo**, **Blog** y **Contacto**.
- **Diseño Luxury Minimalist ("Studio Noir")**: Paleta cromática profunda (`#030304`, `#0e0f13`) con tipografía editorial (*Playfair Display* & *Montserrat*), detalles dorados y acentos en alto contraste con legibilidad garantizada.
- **Catálogo Inteligente (85+ Referencias Originales)**:
  - Filtro intuitivo por **Tipo Simple / Estilo Olfativo** (*Dulces / Frutales*, *Amaderadas y Fuertes*, *Frescas y Cítricas*, *Elegantes y Sofisticadas*, *Orientales y Especiadas*, *Florales Delicadas*, *Clásicas y Versátiles*).
  - Selectores dinámicos por **Casa Perfumera** (Lattafa, Afnan, Armani, Carolina Herrera, Jean Paul Gaultier, etc.) y **Familia Olfativa**.
  - Buscador predictivo en tiempo real por nombre, marca o notas olfativas.
  - Paginación interactiva y ficha técnica modal completa con arquitectura olfativa (salida, corazón, fondo), pitch de venta y botón directo de pedido por WhatsApp.
- **Blog de Cultura Olfativa con Vitrina Relacionada**: Artículos estructurados con terminología SEO colombiana, consejos de fijación en clima de Medellín, guías para identificar perfumes originales y carrusel de fragancias sugeridas.
- **Módulo de Contacto & Geolocalización**:
  - Mapa interactivo de Google Maps embebido con pin exacto en la sede física: **Cra. 86B #47A-40, Barrio Floresta / La América, Medellín**.
  - Horarios de atención y accesos directos a WhatsApp de ventas con mensajes preconfigurados.
- **Testimonios Verificados**: Reseñas de clientes con batch code confirmado y despacho a nivel nacional.

## 🚀 Despliegue y Uso Local

Para abrir la tienda en tu equipo, simplemente abre `index.html` en cualquier navegador web moderno:
```bash
Start-Process "index.html"
```
No requiere servidores externos ni bases de datos activas: todo el catálogo, lógica y recursos se procesan de manera local y autónoma.
